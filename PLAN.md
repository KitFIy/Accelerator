## Что такое проект (коротко)

Axisec — шлюз (Policy Enforcement Point) между ИИ-агентом и инфраструктурой
компании. Он перехватывает исходящие вызовы инструментов агента
(Function Calling, MCP), разбирает их детерминированно (AST для SQL,
схемы для аргументов API, DLP для ответов) и блокирует то, что запрещено
политикой, — независимо от того, каким промптом агента к этому склонили.
Плюс модуль Red Team: прогон агента по сценариям атак до вывода в прод.

Дедлайны из исходной презентации: ядро 15.11.2026, тестирование 25.11.2026,
релиз MVP и Demo Day 30.11.2026.

## Принятые решения (по умолчанию, можно поменять)

1. Дизайн презентаций — исходный шаблон Акселератора РТУ МИРЭА сохраняется,
   меняется содержание.
2. MVP запускается одной командой и работает офлайн: встроенный «уязвимый
   агент» и имитатор LLM. Реальную LLM (GigaChat, YandexGPT, любая
   OpenAI-совместимая) можно подключить через переменные окружения.
3. Дашборд — одна страница, отдаётся самим шлюзом (без отдельной сборки
   Next.js): на защите меньше точек отказа.
4. В материалах остаются только цифры с источником либо измеренные на MVP.
   Непроверяемые утверждения убираются или переформулируются.
